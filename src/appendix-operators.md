## 常用类型转换矩阵

新手最常卡住的不是语法，是"这俩类型怎么互相变"。两张矩阵一劳永逸：

### 数字转换矩阵

> 📝 **口诀**：小转大用 `into()`（无损失），大转小用 `try_from()`（可能溢出），浮点转整型用 `as`（截断小数）。

| 从 \ 到 | 整数 | 浮点 | 字符串 |
|---------|------|------|--------|
| **整数** | `T::from(x)` 或 `x as T` | `x as f64` | `x.to_string()` |
| **浮点** | `x as i32`（⚠️ 截断小数） | `x as f32`（精度损失） | `x.to_string()` |
| **字符串** | `s.parse::<i32>()?` | `s.parse::<f64>()?` | — |

```rust
fn conversions() -> Result<(), std::num::ParseIntError> {
    let a: i64 = i32::MAX.into();             // 小 → 大，永远安全
    let b: Result<u8, _> = 300u16.try_into(); // 大 → 小，可能溢出（300 > 255 → Err）
    let c: i32 = 3.7_f64 as i32;              // 浮点 → 整数，截断为 3
    let d: i32 = "42".parse()?;               // 字符串 → 数字（? 上抛错误）
    let e = 42i32.to_string();                // 数字 → 字符串
    println!("{a} {b:?} {c} {d} {e}");
    Ok(())
}
```

### 字符串转换矩阵

> 📝 **口诀**：拥有型（`String`/`PathBuf`）→ 借用型（`&str`/`&Path`）用 `.as_str()`/`.as_ref()`；反过来用 `.to_string()` / `.to_owned()`。

| | → `String` | → `&str` | → `PathBuf` | → `Vec<u8>` |
|---|---|---|---|---|
| **`String`** | — | `s.as_str()` | `PathBuf::from(s)` | `s.into_bytes()` |
| **`&str`** | `s.to_string()` | — | `PathBuf::from(s)` | `s.as_bytes().to_vec()` |
| **整数** | `x.to_string()` | — | — | — |

> ⚠️ **新手坑**：浮点数永远不要用 `==` 比较——用 `(a - b).abs() < 1e-10` 判断"近似相等"。还有 `as` 转换是静默截断（`3.7 as i32` 是 `3` 不是 `4`），拿不准就用 `try_into()` 拿到 `Result`。
