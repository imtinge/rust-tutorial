## 学习路线图

学习顺序依次推进：第 1 阶段 → 第 2 阶段 → 第 3 阶段 → 第 4 阶段 → 第 5 阶段，最后进入五个实战项目。

| 阶段 | 建议时长 | 包含章节 |
|------|----------|----------|
| 第 1 阶段 | 1-2 天 | Ch1 环境、Ch2 语法 |
| 第 2 阶段 | 3-5 天 | Ch3 所有权、Ch4 结构体、Ch5 枚举、Ch6 集合 |
| 第 3 阶段 | 6-8 天 | Ch7 泛型、Ch8 生命周期、Ch9 迭代器、Ch10 进阶、Ch11 异步、Ch12 测试 |
| 第 4 阶段 | 2-3 天 | Ch13 编译错误、Ch14 内存布局、Ch15 FFI |
| 第 5 阶段 | 2-3 天 | Ch16 WASM、Ch17 Cargo 进阶、Ch18 AI 生态 |
| 实战阶段 | — | 实战 1 Todo、实战 2 爬虫、实战 3 Web 服务器、实战 4 Redis、实战 5 Axum API |

### 各阶段建议

**第1阶段**：跟着敲代码，不要跳过环境搭建。重点是"让程序跑起来"。

**第2阶段**：这是最关键的阶段。所有权和借用是 Rust 的核心，反复练习到"肌肉记忆"。遇到编译器报错不要跳过——读懂它、修复它。

**第3阶段**：进阶特性。泛型和 Trait 是代码复用的关键；生命周期是最难的，多看几遍；迭代器让代码更 Rust 风格；第 11 章异步让你一个线程照应海量任务；第 12 章测试让代码值得信赖。

**第4阶段**：痛点攻坚。编译错误专章帮你建立"与编译器合作"的心态；内存布局可视化让你"看得透"；Unsafe/FFI 扩展你的能力边界。

**第5阶段**：应用方向。WebAssembly 让 Rust 进入浏览器——这是 Rust 独有的优势方向；Cargo 进阶教你用工作空间、features、发布流程把项目组织成生产级形态；AI 生态章带你用已学知识接入大模型——两条路线（本地推理/调 API）任你选。

**实战阶段**：不要只看代码——亲手写出来。从 Todo 到 Axum API，难度递增，每个项目都串联前面学的所有知识点。

## 常见报错速查

| 错误码 | 含义 | 常见原因 |
|--------|------|----------|
| E0382 | use of moved value | 使用了已移动的变量 |
| E0384 | cannot assign twice to immutable | 修改不可变变量，忘加 `mut` |
| E0277 | trait not satisfied | 泛型类型没实现要求的 Trait |
| E0308 | mismatched types | 类型不匹配（如忘了去掉分号） |
| E0502 | borrowed as mutable | 可变和不可变引用冲突 |
| E0596 | cannot borrow as mutable | 不可变变量借为可变引用 |

> 💡 **技巧**：看到报错先看**错误码**（E0xxx），再看**行号**，最后看**提示信息**。Rust 的报错信息通常已经告诉你怎么修了。

## 学习心态

> *「学 Rust 就像学骑自行车——刚上车时摇摇晃晃摔几跤，但一旦掌握了平衡，你就会惊叹：这也太快了吧！」*

- 编译器报错不是在找你麻烦，是在帮你排雷
- 所有权和生命周期一开始会卡——这是正常的，多写几遍就通了
- 不要一开始就追求"Rust 风格"的完美代码——先让代码跑起来，再优化
- 每天写一点比一次学很多更有效

**祝你在 Rust 的世界里一路顺风！** 🦀
