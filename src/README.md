# Rust 从入门到上手实战

> *「学 Rust 就像学骑自行车——刚上车时摇摇晃晃摔几跤，但一旦掌握了平衡，你就会惊叹：这也太快了吧！」*

## 你好，未来的 Rustacean！

欢迎来到《Rust 从入门到上手实战》！

我是你的 Rust 导师，一个经历过无数次编译器"毒打"后依然热爱这门语言的资深工程师。接下来的旅程中，我会用最接地气的大白话、最生活化的比喻，带你从零开始掌握 Rust——这门连续多年蝉联 Stack Overflow "最受喜爱编程语言" 桂冠的语言。

## 这本书适合谁？

一句话：**零基础也能上手**——你不需要提前懂任何编程语言，我们从下载安装、写第一行代码讲起，每个概念都有生活比喻和可运行示例。

- **完全没写过代码的纯新手**：愿意跟着动手敲，第 1 章装好环境就能跑起第一个程序
- **有 Python / JavaScript / Go 等语言基础的开发者**：想搞懂"所有权""生命周期"到底是什么，用 Rust 写出又快又安全的程序；书中 🐍 类比框会帮你把新旧知识快速对上号
- **已经在学 Rust、总被红色报错拦住的人**：第 13 章报错攻坚和全书的真实编译器输出讲解，会帮你翻过去

### 渐进式学习路径

```
Hello World → 基础类型 → 所有权/借用 → 结构体/枚举
→ 泛型/Trait → 生命周期/闭包 → 迭代器/模块
→ 智能指针/并发 → async/await → 测试 → 编译错误攻坚
→ 内存布局 → Unsafe/FFI → WebAssembly → Cargo 进阶
→ 实战项目（CLI → 文件 → Web → Redis → API → GUI）
```

## 一句话总结 Rust 的学习曲线

> Rust 的学习曲线像一座山：前面有段陡坡（所有权、借用、生命周期），翻过去之后就是一片平坦的高原，可以自由驰骋。陡坡确实陡，但我保证——每一步都有绳子（编译器）拉着你，摔不死。

## 教学风格说明

- **比喻先行**：所有权 = 奶茶杯的使用权，借用检查器 = 宿舍查寝阿姨，生命周期 = 奶茶的保质期，Rust vs C/C++ = 带空仓警告的神奇钉枪，堆内存 = 酒店地下行李仓库，GC 开销 = 穿全套盔甲走路……硬核概念全用生活场景解释
- **代码先行**：每个知识点先上代码，再讲原理——先看效果再理解，符合人类学习规律
- **报错是朋友**：编译器报错不是你的敌人，是帮你排雷的战友。我们会展示真实的编译器输出（如 `error[E0382]`），逐行拆解每一行含义
- **每章有 Mini Project**：学一个概念，立刻用一个项目巩固（第1-17章全部配有）
- **每章有记忆卡片**：章末浓缩成一句话 + 口诀 + 三个判断题，考前复习就靠它

### 关于代码块的 ✅ / 📎 标记

代码块按"能不能直接拿走运行"分三种身份：

| 身份 | 标记 | 含义 |
|------|------|------|
| **完整可运行** | ✅ | 块内含完整 `fn main`（或完整文件），复制进 `src/main.rs` 直接 `cargo run`，不依赖上文 |
| **片段** | 📎 | 为分步讲解，一个完整程序被拆成若干小块；只复制一块跑不起来。每块以 `📎 片段 N/M` 标明它在第几块 |
| **正文示例** | 无标记 | 默认身份：可能是一段可独立运行的程序、一个函数/结构体定义，或在已建立上下文里新增的内容——跟着正文操作即可 |

## 参考资源配合使用：完整的 Rust 学习工具链

本书整合了五个参考资源的精华，建议学完后配合以下资源使用，形成完整学习工具链：

| 参考资源 | 定位 | 什么时候用 |
|----------|------|-----------|
| **《Rust 语言圣经》(rust-course)** | 系统学习理论 | 学完本书后想深入某个主题时查阅 |
| **《通过例子学 Rust》(rust-by-example)** | 通过运行代码加深理解 | 想看更多可运行示例时翻阅 |
| **cheats.rs** | 日常速查工具 | 写代码时忘了语法/方法名时速查 |
| **TRPL（Rust 程序设计语言）** | 官方权威解读 | 尤其 2024 edition 的 async/await 新章节，其他教程均未跟进 |
| **Rust All-in-One For Dummies** | 实际应用方向 | 参考资源中唯一以整章篇幅讲 WebAssembly 的，用 Axum 教 Web 开发 |

> 📌 **要点**：如果只读一本进阶书，读 TRPL——它是官方权威，2024 edition 的 async/await 章节是其他教程尚未跟进的独家内容。
