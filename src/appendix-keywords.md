# 附录A：Rust 关键字速查表

> 以下是 Rust 的关键字。**严格关键字（strict keywords）不能用作标识符**——不能拿它们当变量名或函数名。另有一类**弱关键字（weak keywords）**（如 `union`、`macro_rules!` 中的 `macro_rules`），只在特定语法位置才有特殊含义，在其他位置仍可作普通标识符（可实测：`let union = 1;` 编译通过）。

## 关键字分类

### 用于声明

| 关键字 | 说明 | 出现章节 |
|--------|------|----------|
| `let` | 声明变量 | 第1/2章 |
| `mut` | 标记可变 | 第1/2章 |
| `const` | 声明常量 | 第2章 |
| `static` | 静态变量（全局变量）；`'static` 生命周期 | 第8/15章 |
| `fn` | 声明函数 | 第1/2章 |
| `struct` | 声明结构体 | 第4章 |
| `enum` | 声明枚举 | 第5章 |
| `trait` | 声明 Trait | 第7章 |
| `impl` | 实现方法/Trait | 第4章 |
| `mod` | 声明模块 | 第9章 |
| `use` | 引入路径 | 第9章 |
| `type` | 声明类型别名（如实战 5 的 `type Db = ...`）；在 trait 里声明关联类型 | 第9/10章、实战5 |
| `extern` | 调用 C 语言的函数（像请外援）；edition 2024 起 extern 块写作 `unsafe extern` | 第15章 |

### 用于控制流

| 关键字 | 说明 | 出现章节 |
|--------|------|----------|
| `if` / `else` | 条件分支 | 第2章 |
| `match` | 模式匹配 | 第5章 |
| `loop` | 无限循环 | 第2章 |
| `while` | 条件循环 | 第2章 |
| `for` | 遍历循环 | 第2章 |
| `in` | for 循环中 | 第2章 |
| `break` | 跳出循环 | 第2章 |
| `continue` | 跳过本次 | 第2章 |
| `return` | 返回值 | 第2章 |

### 用于类型与泛型

| 关键字 | 说明 | 出现章节 |
|--------|------|----------|
| `as` | 数值类型转换（`x as f64`）；导入重命名（`use a as b`） | 第4/9/10章 |
| `where` | Trait 约束 | 第7章 |
| `dyn` | 类似其他语言接口的运行时多态（虚表分发） | 第7章 |
| `Self` / `self` | 当前类型/实例 | 第4/7章 |
| `super` | 引用父模块，就像文件系统里的 `..`（上一级目录） | 第9/12章 |
| `crate` | 引用当前包的根，就像文件系统里的 `/`（根目录） | 第9章 |
| `ref` | 在模式匹配中创建引用，而不是移动值 | 本书未展开 |

### 用于异步与并发

| 关键字 | 说明 | 出现章节 |
|--------|------|----------|
| `async` | 标记异步函数，告诉编译器"这个函数可以暂停和恢复" | 第11章、实战3/4/5 |
| `await` | 等待异步操作完成，就像等外卖送达 | 第11章、实战3/4/5 |
| `move` | 闭包获取所有权 | 第8/11章 |
| `unsafe` | 不安全代码 | 第15章 |

### 其他

| 关键字 | 说明 | 出现章节 |
|--------|------|----------|
| `pub` | 公开可见性，不加 `pub` 默认仅模块内部可见 | 第9章 |
| `true` / `false` | 布尔值 | 第2章 |
| `union` | 联合体，多个字段共享同一段内存（不安全，新手不用） | 第15章 |
| `box` | 保留未启用的关键字，实际写法是 `Box::new()` | - |
| `macro_rules!` | 声明宏（内建宏，非关键字） | 第10章 |

### 保留未使用的关键字

以下关键字目前**保留但未使用**——不能用作标识符，但语言本身还没启用它们：

`abstract` `become` `do` `final` `macro` `override` `priv` `typeof` `unsized` `virtual` `yield` `try` `gen`

> 📌 **要点**：`try` 自 2018 edition 起保留，`gen` 自 2024 edition 起为将来的生成器语法（gen blocks）保留——拿它们当变量名会直接编译报错。

### 弱关键字

弱关键字只在特定语法位置有特殊含义，其他位置仍可作普通标识符：

| 弱关键字 | 特殊含义的位置 | 作普通标识符 |
|----------|----------------|--------------|
| `union` | 声明联合体 `union U { ... }` | `let union = 1;` ✓ |
| `macro_rules` | `macro_rules!` 宏声明中 | `let macro_rules = 1;` ✓ |
| `raw`（edition 2024） | 裸引用 `&raw const/ mut x` 中 | 其余位置可作标识符 |
| `safe`（edition 2024） | `safe fn` / `unsafe extern` 块中 | 其余位置可作标识符 |

> 💡 **技巧**：看到不认识的关键字时回来查这个表。不用一次全记住，用多了自然就熟了。
